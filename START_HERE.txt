🎨 COMO USAR O EDITOR

1. CRIAR FLUXO
   Dashboard → [+ Novo Fluxo]

2. ADICIONAR COMPONENTES
   Painel esquerdo → Arraste componente para canvas

3. EDITAR PROPRIEDADES
   Clique no nó → Painel direito mostra propriedades

4. CONECTAR NÓDULOS
   Clique e arraste entre os handles (bolinhas)

5. DELETAR
   Selecione nó → Pressione Delete

6. NAVEGAÇÃO
   • Zoom: Scroll ou Ctrl+Scroll
   • Pan: Espaço + Arraste
   • Minimap: Canto inferior direito
